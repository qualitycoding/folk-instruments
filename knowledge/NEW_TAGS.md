# Tags first used by this run

To be added to the stores' `TAXONOMY.md` files in `S-KNOW`.

- `subject:free-reed-modelling`: physical models of free reeds (harmonica, accordion, melodion, harmonium) for synthesis
- `subject:harmonica-acoustics`: harmonica layouts, bends and their physics
- `subject:accordion-acoustics`: accordion registers, tremolo tuning, tone chambers and measured notes
- `subject:melodica`: the melodica (melodion, pianica): construction and ranges
- `subject:plucked-string-modelling`: stiff strings, coupled string pairs, plucks and string damping for synthesis
- `subject:mandolin-acoustics`: mandolin body modes, strings and scales
- `subject:bouzouki`: Greek and Irish bouzouki tunings, strings and body data
- `subject:folk-instrument-reference-recordings`: reference recordings of harmonica, accordion, melodion, mandolin and bouzouki and their licences
- `subject:python-test-tooling`: pinned Python packages used for audio tests
- `tech:claude-code-cloud`: Claude Code cloud sessions as a planning or implementation environment
